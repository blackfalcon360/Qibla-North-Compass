# Qibla & North 🕋

Compass dial showing North (red) and Qibla (green, with Kaaba icon), the Qibla bearing,
turn-left/right guidance, distance to the Kaaba, and a Refresh-location button.
Works fully offline (no INTERNET permission): compass sensor + GPS + built-in math.
Auto portrait / landscape, full screen, black background.

Brought to you By: Black Falcon 🦅

## Build
Push to GitHub -> Actions -> "Build APK" -> download `QiblaNorth-APK`.
Local: `gradle assembleDebug` (JDK 17, Gradle 8.7+).
